For Loop --> When we know number of iteration used for loop.

syntax:
        for i in range(start , stop , step):

Example:
        n=6
        for i in range(1,n):   ***** loop always run n-1 *****
    Output:
            1
            2
            3
            4
            5

While Loop --> A while loop is used to repeatedly execute block of code as given condition is true.

syntax:
        while(condition):

Example:
        i = 1
        while(i <= 5):
            print(i)
            i+=1
    Output:
            1
            2
            3
            4
            5
